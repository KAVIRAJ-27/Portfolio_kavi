## 🌟 Highlights & Key Features

* **Futuristic "AI Developer Lab" Aesthetic**: Deep obsidian theme with glassmorphism, subtle glowing borders, and responsive light/dark mode persistence.
* **Interactive Constellation Canvas**: Real-time interactive node canvas connecting `AI → Data → Code → IoT → Mobile → Web` responding smoothly to cursor motion.
* **Dynamic Role Typist**: Automated role cycler (*AI Developer, Full-Stack Developer, Android Developer, IoT Enthusiast, Problem Solver*).
* **Interactive Career Evolution Timeline**: 5-stage progression pathway:
  $$\text{Student} \longrightarrow \text{Learner} \longrightarrow \text{Builder} \longrightarrow \text{Project Developer} \longrightarrow \text{Future AI Engineer}$$
* **Skills Constellation**: Categorized technology matrix (*Programming, AI / Data, Web, Mobile, Database, Tools*) with interactive contextual inspector.
* **Featured Projects & Explorer**: Real-time search and category filtering with detailed architecture modals.
  * **QuantumLearn**: SIH project with 35 guided lessons, Qiskit circuit builder, statevector probability visualization, and Socratic AI mentor.
  * **HydroReminder**: Local-first Android water reminder with an **interactive phone mockup simulator**.
  * **Location Recorder**: Privacy-first GPS travel history logger with **simulated route timeline** and **biometric export gate**.
  * **Academic Resource Allocation Dashboard**: Optimization algorithms and utilization analytics.
  * **AI Stress Prediction System**: Random Forest classification model (~88.64% test accuracy).
* **Exploring IoT & Smart Systems**: Visual telemetry pipeline (`Sensor → Edge → Processing → AI → Database → Dashboard`) and interactive sensor matrix.
* **Developer CLI Terminal**: Interactive shell supporting `help`, `whoami`, `about`, `projects`, `skills`, `journey`, `hackathon`, `contact`, `resume`, `theme`, and `clear`.
* **Easter Egg Command Palette (`Ctrl + K` / `Cmd + K`)**: Global modal for rapid keyboard navigation across sections.
* **Contact & Collaboration**: Direct form validation with immediate mailto fallback and 1-click email copy.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm, pnpm, or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/KAVIRAJ-27/Portfolio_kavi.git

# Navigate into the project directory
cd Portfolio_kavi

# Install dependencies
npm install
```

### Running Locally
```bash
# Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production
```bash
# Build the application
npm run build

# Run the production server
npm run start
```
